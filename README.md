# The Meridian Atlas

A single illustrated world-news front page for Tuesday, 17 November 2026. The page pairs an atlas-inspired map and editorial typography with original inline SVG drawings for the summit and each of the seven other dispatches.

Run `node render.mjs` to produce `entry.png` at 1024×1024. Run `node main.ts` to copy it into `MAKEFUN_OUTPUT_DIR`, or `/output` when that variable is unset.
